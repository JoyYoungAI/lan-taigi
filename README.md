## 🚀 十一大功能模組介紹

### 1. 🍜 台灣各地特色小吃與夜市客製點餐對話庫 (Taiwan Regional Snacks)
* **全台 16 縣市 30 款經典在地名點**：
  * **北部名點**：基隆鼎邊薖、淡水阿給、深坑臭豆腐、台北滷肉飯、新竹摃丸湯、新竹炒米粉。
  * **中部古味**：台中太陽餅、逢甲大腸包小腸、彰化肉圓、彰化爌肉飯、鹿港牛舌餅、鹿港麵線糊。
  * **南部府城**：嘉義火雞肉飯、嘉義白醋涼麵、台南擔仔麵、台南溫體牛肉湯、台南鱔魚意麵、台南棺材板、安平虱目魚肚、旗津烤黑輪、岡山羊肉爐、屏東萬巒豬腳、潮州冷熱冰。
  * **東部與離島**：宜蘭鴨賞、宜蘭糕渣、花蓮扁食、台東柴魚米苔目、澎湖黑糖糕、澎湖野生花枝丸、金門石蚵蚵嗲。
* **三大維度地道實戰例句**：
  1. 💬 **真實點餐溝通**：點餐份量、辣度調整、去芫荽、加蒜泥、包外帶等日常生活對話。
  2. 👅 **道地口感評語**：熟練運用「𩚬 (khiū)」、「芳 (phang)」、「臊 (tsho)」、「甘甜 (kam-tinn)」、「脆 (tshuè)」等味覺詞彙。
  3. 📜 **小吃典故與生活俗諺**：探索小吃命名的歷史脈絡與在地常民文化。
* **🏮 夜市點餐客製化對話產生器**：自由勾選內用/外帶、份量大小、辣度、蒜泥、香菜與肥瘦，即時動態組合台語整句漢字、臺羅拼音、華語翻譯與語音播放，一鍵加入 SM-2 複習佇列！

### 2. 🗺️ Duolingo 風格闖關地圖與階段通關 (Level Road Map)
* **S 型蜿蜒關卡道路**：將 10 大情境單元拆解為 **40 個漸進式挑戰關卡**（每單元 4 節點），支援左右交錯視覺動畫、星級評分（★ 1~3 星）與動態脈衝節點。
* **四大闖關階段 (Progressive Sub-Stages)**：
  1. 📘 **詞彙初探**：高頻核心生詞學習、例句與真人台語發音沉浸。
  2. 👂 **聽力認字**：純聽台語音檔進行漢字與拼音選擇測驗。
  3. 🎤 **口說聲調挑戰**：透過麥克風即時錄音，進行 100% 離線調型評分。
  4. 🏆 **會話通關大考驗**：綜合情境對話角色扮演與通關測驗，全通關即解鎖下一單元並自動將生詞登錄至複習庫。

### 2. 🧠 SM-2 間隔重複記憶引擎 (Spaced Repetition System)
* **經典 SuperMemo SM-2 演算法**：根據記憶難易度係數（EF）、複習次數與間隔天數（$I(n) = I(n-1) \times EF$），科學化規劃單詞複習時程。
* **每日學習儀表板**：地圖頂部即時顯示連續學習天數（Streak 🔥）、今日待複習單詞數（🎯）、累計通關星數（🌟）與已精通單詞量（🧠）。
* **四級反饋複習卡片**：提供「重來 (Again)」、「困難 (Hard)」、「良好 (Good)」、「容易 (Easy)」即時按鈕評分，自動滾動調整最佳記憶間隔。

### 3. 🎤 100% 離線 Web Audio 音高調型評分器 (Speech Pitch Tracker)
* **零依賴純前端聲學分析**：利用 Web Audio API 原生 `AnalyserNode` 與時域自相關函數（Autocorrelation），精確擷取 70Hz ~ 450Hz 的基頻軌跡（F0 Pitch Contour）。
* **台語七聲調標準調型對比**：內建教育部標準調值（55, 51, 31, 21, 24, 33, 53），自動比對使用者滑音斜率與目標曲線並給予評分（80+ 分通過）。
* **HTML5 Canvas 即時動態軌跡視覺化**：繪製使用者音高即時動態折線圖與標準調型輔助線，支援錄音即時重播回聽對比。

### 4. 🎓 系統性主題情境教學 (Themed Lessons)
* 收錄 10 大生活情境單元（30+ 篇對話）：
  1. **見面問候與日常禮節**（汝好、食飽未、多謝、勞力、失禮、歹勢、無要緊、再會）
  2. **數字、金錢與時間計量**（一至萬、文白異讀、箍、點鐘、禮拜）
  3. **台灣美食小吃與夜市巡禮**（滷肉飯、肉圓、麵線、番麥、割包、枵、芳）
  4. **親屬稱謂與家庭關係**（阿公、阿媽、阿爸、阿母、牽手、後生、囡仔）
  5. **人體器官、感覺與情緒**（頭、目睭、跤手、歡喜、受氣、見笑、忝）
  6. **常用生活動作與動詞**（食、啉、看、聽、講、行、走、睏、買、賣）
  7. **交通出行與方位問路**（孔明車、火車、捷運、正手爿、倒手爿、頭前、後壁）
  8. **生活勞動、職業與職場**（頭路、做工課、賺食、拍拚、公司）
  9. **天氣氣候與自然景物**（好天、落雨、做風颱、熱、寒、日頭、月娘）
  10. **經典俗諺與生活智慧**（食緊弄破碗、一兼二顧摸蜊仔兼洗褲、戲棚跤企久人的）
* 每單元提供：**情境對話（含真人台語音讀）、核心單詞卡、3D 單字翻翻卡複習、文化與文法錦囊**，並支援一鍵切換「闖關地圖」與「傳統列表」視圖。

### 2. 📖 全功能離線辭典 (Full Offline Dictionary - 29,592 Entries)
* **極速搜尋 (< 10ms)**：即打即找，支援漢字、臺羅拼音（模糊調號搜尋，如打 `tai-gi`、`taigi` 或 `tâi-gí` 皆可精準匹配）、華語釋義關鍵字搜尋。
* **分類篩選晶片**：美食、用品、節令、個性、身體、交通、動物等 10+ 分類切換。
* **完整詞條卡片**：
  * 主詞目與附屬詞目
  * 詞性分類（名詞、動詞、形容詞、副詞、數詞等）
  * 詳細詞義分項解說
  * 官方權威例句與對照翻譯
  * 十大方言語音腔調差異（鹿港/三峽/臺北偏泉、宜蘭/臺中偏漳、臺南/高雄混合、金門/新竹/馬公等）
  * 又唸作、合音唸作、俗唸作、異用字

### 3. 🎵 臺羅聲韻調學院 (Phonology & Web Audio Tone Synthesizer)
* **教育部臺灣台語羅馬字拼音方案 (Tâi-lô)** 系統化解說：
  * **17 聲母**（含清濁對立 b, g, m, n, ng 國際音標與示範詞）
  * **韻母表**（單元音、複元音、鼻化韻、入聲塞音尾 -p, -t, -k, -h）
  * **八聲七調圖解**（陰平、陰上、陰去、陰入、陽平、陽去、陽入）
* **Web Audio 聲調物理合成器**：
  * 根據語言學聲學 F0 基頻曲線，利用 Web Audio API OscillatorNode 物理合成 55, 51, 31, 21, 24, 33, 53 的調值連續滑音！
  * **互動式調值曲線座標圖**：點擊任一聲調曲線即刻發音並高亮軌跡。
* **連讀變調口訣教學（Tone Sandhi）**：
  * 口訣：**5 ➔ 7 ➔ 3 ➔ 2 ➔ 1 ➔ 7** 與 **4 ➔ 8 / 8 ➔ 4**。
  * 互動式變調計算機：點擊任意聲調，即時連續播放「本調 ➔ 變調」的發音對比。

## 💻 快速啟動與使用指南

### 本地直接啟動

只需使用任何靜態 Web 伺服器即可開啟（支援 Service Worker 與 PWA）：

```bash
# 切換至專案目錄
cd /Users/tonny/agy/zh-hant

# 使用 Python 內建 HTTP 伺服器
python3 -m http.server 8080

# 或使用 Node.js npx serve
npx serve -l 8080
```

開啟瀏覽器造訪：`http://localhost:8080`

### 安裝為桌面 / 手機 App (PWA)
1. **Google Chrome / Edge (電腦版)**：點擊網址列右側的「安裝」圖示，或頁面右上角的「安裝 App」按鈕。
2. **iPhone / iPad (Safari)**：點擊底部的「分享」按鈕，選擇「加入主畫面」。
3. **Android (Chrome)**：點擊右上角選單「加到主畫面」或直接點擊提示安裝。

安裝完成後，App 會像原生應用程式一樣具備獨立視窗、應用圖示，且在飛航模式（完全斷網）下仍能流暢搜尋、背單字、做測驗與播放音效！
